# Attribution / 参考来源

This open-source build is based on better-dsh-session-deletetool 0.7.5 by Lzcdebear.
本开源版本参考并基于 Lzcdebear 的 better-dsh-session-deletetool 0.7.5 改造。

Original project / 原项目：

The original plugin provided the session family tree, batch deletion flow, Host/Client architecture, and interaction design. This build adds cross-workspace artifact resolution, manifest and sidecar binding, explicit create-and-bind, workspace-level binding installer, and related tests/docs.
原插件提供了会话家族树、批量删除流程、Host/Client 架构和交互设计。本版本增加了跨工作区产物目录解析、manifest 与 sidecar 绑定、显式创建并绑定、工作区级安装脚本以及相关测试和文档。
